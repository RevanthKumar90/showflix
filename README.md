# ShowFlix 🎬

TV Shows Explorer Web App built using HTML, Tailwind CSS, and JavaScript.

## 🚀 Live Demo
https://showflix-seven.vercel.app/

## 📂 GitHub Repository
https://github.com/RevanthKumar90/showflix

## 🔥 Features
- TVMaze API Integration
- Dynamic DOM Rendering
- Search Functionality
- Top Rated Filter
- Modal UI
- Fully Responsive Design

## 🛠 Tech Stack
- HTML
- Tailwind CSS
- JavaScript
- Vercel (Deployment)
